# IPv4アドレス 2進数 → 10進数 変換ドリル（教育用）

IPv4 アドレスを **2進数表記から10進数表記に変換する** 練習問題の Web アプリです。

## 内容

### 📘 しくみ
- IPv4 アドレスは32ビット。8ビット（1オクテット）ずつ4つに区切って10進数に直す
- 各けたの重み（128・64・32・16・8・4・2・1）を使った変換方法
- サブネットマスクでよく出る値（128, 192, 224, 240, 248, 252, 254, 255）
- IPアドレスの各部分：ネットワーク部とホスト部、サブネットマスクとの関係、アドレスの種類（プライベート・ループバック・グローバル）

### ✏️ 練習問題（1セット10問）
| レベル | 出題 | 例 |
| --- | --- | --- |
| 1：8ビット | 1オクテットを10進数に | `10101000` → `168` |
| 2：IPv4アドレス | ドット区切りの32ビット | `11000000.10101000.00000001.00000001` → `192.168.1.1` |
| 3：区切りなし | ドットなしの32ビットを自分で8けたずつ区切る | `11111111111111111111111100000000` → `255.255.255.0` |
| 4：サブネットマスク | 10進数のマスクを2進数に直し、ネットワーク部・ホスト部のけた数を答える | `255.255.240.0` → `11111111.11111111.11110000.00000000`、ネットワーク部 20 けた／ホスト部 12 けた |

- 問題は毎回ランダムに作られます（プライベートアドレスやサブネットマスクも混ざります）
- 「ヒント」で重みの表を表示、答え合わせ後は重みのたし算で解説
- 答え合わせ後の「このアドレスについて」で、アドレスの種類と、ネットワーク部・ホスト部を色分けした2進数を表示（サブネットマスクは /N とホスト数も）
- 入力欄は3けた（2進数の欄は8けた）入力か「.」で次の欄へ移動、Enter で答え合わせ／次の問題
- 1問以上答えたあとは「ここで終わる」で途中終了でき、その時点の正解率で結果画面が出ます
- 結果画面（正解率・正解数・途中終了の表示・ヒント使用数・日時・全問の見直し）はスクリーンショットで提出する想定です（結果はサーバに保存されません）

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-ipv4-binary-quiz/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-ipv4-binary-quiz/ （`.github/workflows/deploy-ftp.yml`）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります（edu-network-simulator と同じ値）。
