# IPv4アドレス 2進数 → 10進数 変換ドリル（教育用）

IPv4 アドレスを **2進数表記から10進数表記に変換する** 練習問題の Web アプリです。

## 内容

### 📘 しくみ
- IPv4 アドレスは32ビット。8ビット（1オクテット）ずつ4つに区切って10進数に直す
- 各けたの重み（128・64・32・16・8・4・2・1）を使った変換方法
- サブネットマスクでよく出る値（128, 192, 224, 240, 248, 252, 254, 255）

### ✏️ 練習問題（1セット10問）
| レベル | 出題 | 例 |
| --- | --- | --- |
| 1：8ビット | 1オクテットを10進数に | `10101000` → `168` |
| 2：IPv4アドレス | ドット区切りの32ビット | `11000000.10101000.00000001.00000001` → `192.168.1.1` |
| 3：区切りなし | ドットなしの32ビットを自分で8けたずつ区切る | `11111111111111111111111100000000` → `255.255.255.0` |

- 問題は毎回ランダムに作られます（プライベートアドレスやサブネットマスクも混ざります）
- 「ヒント」で重みの表を表示、答え合わせ後は重みのたし算で解説
- 入力欄は3けた入力か「.」で次の欄へ移動、Enter で答え合わせ／次の問題
- 結果画面（正解数・ヒント使用数・日時・全問の見直し）はスクリーンショットで提出する想定です（結果はサーバに保存されません）

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして GitHub Pages に公開します（リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください）。
